# Inductive Set 
An inductive [[Set]] of [[Real Number]]s is called inductive if it has the following two properties: 

1. $1$ is in the set 
2. For every $x$ in the set, $x+1$ 

For some examples, $\mathbb{R},\mathbb{R}^+$ are both inductive sets.
