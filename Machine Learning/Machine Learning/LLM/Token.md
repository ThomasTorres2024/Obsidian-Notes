# Token

The fundamental unit produced by [[Large Language Model]]s. When text is processed text must be broken down into smaller units, so a paragraph by humans is turned into words. For an LLM this may constitute characters, whole words, subwords, punctuation marks, and so on. It is some set of symbols for a given model.
