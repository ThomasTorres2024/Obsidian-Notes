# Double Negation Elimination 
Given a [[Proposition]] $P$, then we can say that:
$$P \equiv \neg (\neg P)$$
More rigorously:
$$P \iff \neg \neg P$$
Which is to state that negation is an involution. Depending upon different logic systems this result is not always axiomatic and is sometimes a theorem.
