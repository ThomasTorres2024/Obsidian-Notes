# Substitution Cipher 

A simple [[Cryptography]] algorithm where we replace some letter of the alphabet with another letter $n$ letters down from it (we treat the alphabet as a periodic object here). 

An interesting case is $13$ in the algorithm [[Rot13]], which rotates each letter $13$ from its origin The algorithm is interesting since it is its own inverse function. 

This is a very easy algorithm to break due to frequency analysis of certain letters.
