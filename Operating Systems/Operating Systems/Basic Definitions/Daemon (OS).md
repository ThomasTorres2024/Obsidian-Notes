# Daemon Definition
A [[Daemon (OS)]] is a program that runs as a background [[Process (OS)]], rather than being controlled directly by a user. Program that end with a "d" for instance syslogd, are typically daemons, this terminology is generally only used for Unix based systems. 

In windows the related term is "service". In unix, the parent of most daemons is the [[init (Unix)]].
