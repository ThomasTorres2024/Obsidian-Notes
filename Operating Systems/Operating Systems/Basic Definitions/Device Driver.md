# [[Device Driver]]
A [[Device Driver]] is a driver which provides an abstract interface callable by the [[Kernel (OS)]] for hardware on a machine. Despite the specifics of each hardware being unique and distinct among systems, the call to use different functions of the hardware are essentially the same and abstracted so that many different [[Operating System]]s can use them. Most Device Drivers tend to work only in Kernel Space.
