For most commands liike ln, cp, mv, we specify the __original file first__ and then we specify the __file we are moving things to__ in second place. 
### ls 
List the contents of a [[Directory]]
```bash
ls !$ (ls on previous text output)
```

# ln
Hard links between two files
```bash
ln file1.txt file2.txt
```

### cp

Copies an existing file to a new location
